# Task Manager

A full-stack task manager where users can create tasks, set priorities and deadlines, organize them into projects, and receive push notification reminders.

## Tech stack
- React (Vite)
- Node.js + Express
- MongoDB (Mongoose)
- Firebase Cloud Messaging

## Running locally

**Server**
1. `cd server`
2. `npm install`
3. Create a `.env` file with `PORT` and `MONGODB_URI`
4. Add your Firebase `serviceAccountKey.json`
5. `npm run dev`

**Client**
1. `cd client`
2. `npm install`
3. `npm run dev`
